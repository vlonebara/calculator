# Calculator

Небольшой браузерный калькулятор для сложения и вычитания целых чисел. В интерфейсе есть светлая и тёмная темы, справка, удаление последней цифры нажатием на экран и звуковые эффекты.

**Демо:** [vlonebaracalculator.netlify.app](https://vlonebaracalculator.netlify.app/)

## Технологии

- HTML5 — разметка калькулятора;
- CSS3 — адаптивные размеры, оформление и темы через CSS-переменные;
- JavaScript без фреймворков — ввод, арифметика, управление темой и справкой;
- HTML Audio API — звуковые эффекты.

## Структура проекта

```text
calculator/
├── index.html        разметка приложения
├── style.css         стили и адаптация для небольших экранов
├── app.js            логика калькулятора и интерфейса
└── assets/
    ├── audio/        звуки нажатия и вычисления
    ├── fonts/        локальный шрифт
    └── img/          изображения кнопок и тем
```

## Архитектура

Приложение состоит из одной страницы и работает в браузере без сборщика и серверной части. `index.html` задаёт разметку экрана, кнопок и окна справки. `style.css` отвечает за размеры, адаптацию к небольшим экранам, оформление тем и подключение локального шрифта и изображений. `app.js` хранит состояние текущего вычисления, обрабатывает ввод цифр и операций, обновляет дисплей и управляет темой и справкой. Звуки воспроизводятся через HTML Audio API.

Вычисления ограничены сложением и вычитанием целых чисел. Дополнительные библиотеки и установка зависимостей не требуются.

## Запуск

Клонируйте репозиторий и откройте страницу через локальный HTTP-сервер:

```bash
git clone https://github.com/vlonebara/calculator.git
cd calculator
python3 -m http.server 8000
```

Откройте <http://localhost:8000> в браузере. Также можно открыть `index.html` напрямую, но локальный сервер надёжнее загружает аудио и ресурсы.

## Использование

Клавиатурный ввод не предусмотрен: управляйте калькулятором кнопками на странице.

- Нажимайте цифры, затем `+` или `-`, введите второе число и нажмите `=`.
- `ac` очищает экран и текущую операцию.
- Нажатие на число на экране удаляет последнюю цифру.
- Кнопка с луной или солнцем переключает тему.
- Кнопка с вопросительным знаком открывает справку.
